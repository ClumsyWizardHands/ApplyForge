# Source & prior-art research — 2026-09-02

Everything below was live-verified (endpoints probed, licenses read from LICENSE
files, registries counted) — not taken from READMEs. Full receipts in the
session that produced this; summarized here for future work.

## Verified new discovery endpoints (ranked by value/effort)

1. **Getro boards** — one adapter covers General Catalyst (network 222),
   Insight Partners (246), Khosla (257) ≈ 40K jobs w/ comp + DIRECT employer
   ATS apply URLs. `POST https://api.getro.com/api/v2/collections/{id}/search/jobs`
   with `Accept: application/json` EXACTLY (else 406), body
   `{"hitsPerPage":20,"page":0,"query":"account executive","filters":{}}`.
   Filters undocumented — post-filter client-side on returned seniority/locations.
   Caveat: api.getro.com robots.txt disallows; this is the same unauthenticated
   JSON the public board serves — keep volume to a few queries/network/day.
2. **Consider-classic boards** — Sequoia (`jobs.sequoiacap.com`, board
   `sequoia-capital`), Lightspeed (`jobs.lsvp.com`/`lightspeed`, verified e2e),
   Bessemer (`jobs.bvp.com`/`bessemer-ventures`), Kleiner Perkins
   (`jobs.kleinerperkins.com`/`kleiner-perkins`) ≈ 35–40K jobs. Two-step:
   GET /jobs/ (cookie jar, extract `csrfToken` from HTML) → POST
   `/api-boards/search-jobs` with `x-csrf-token`, body
   `{"board":{"id":"...","isParent":true},"query":{"jobTypes":["sales"]},"meta":{"size":20}}`.
   Salary + availableFilters + direct ATS URLs.
3. **chiefofstaff.network** — Webflow RSS: `GET /jobs/rss.xml` (100 items,
   robots-allowed). Useful for Chief of Staff searches: a niche board with many
   such roles. ~1 hour adapter.
4. **a16z (Consider new stack/Convex)** — `GET https://jobs.a16z.com/jobs?q=<term>`
   (also `?jobTypes=sales`); first 25 jobs embedded as `initialData.jobs` JSON
   in HTML (unicode-unescape RSC payload). 19.5K total, salary + direct ATS
   URLs. Slightly brittle; run 5–10 targeted queries, don't paginate the corpus.
5. **USAJOBS + Adzuna** — adapters BUILT (src/jobkit/adapters/feeds/), key-gated;
   see the adapters' docstrings for the verified specs (USAJOBS searches by
   title keywords and, when configured, occupational series and minimum grade;
   Adzuna predicted salaries never treated as posted; redirect_url never
   canonical).

Skipped, with reasons: **Wellfound** (Cloudflare Turnstile + hostile ToS —
actively defended), **YC Work at a Startup** (Algolia key neutered for
anonymous users, ToS prohibits mining, apply URLs gated behind YC accounts —
manual browsing only), **Built In** (open-but-buggy GraphQL that doesn't serve
the search corpus; full corpus is HTML behind an explicit no-bots ToS — the
user's call, default off), **Greylock** (custom site, raw ATS links — cover via the
freehire registry instead).

## Prior-art audit (7 projects)

- **freehire (MIT, alive, the gem):** 210 real Go source adapters / 92 ATS
  families hitting keyless public JSON; `sources/*.yml` = ~230 per-provider
  tenant registries (greenhouse.yml alone ≈ 7,000 board tokens) — MIT data,
  reusable with attribution. Also: URL→(ATS family, board) recognizer with
  per-family URL shapes (icims/oracle/taleo/neogov/comeet/paycom), Common
  Crawl board harvesting. ADOPT: import registry data (NOTICE line), reimplement
  recognizer in discovery.
- **job-apply-plugin (MIT):** best-in-class answer-memory contract — answer
  states confirmed/inferred/missing/sensitive, question.<sha256> normalized
  keys, scope-gated reuse, separate consent timestamps for sensitive values,
  history stores key references never values; plus form/submit-control
  fingerprinting to detect ATS drift. ADOPT ideas at M5.5/M6 polish.
- **LangHire (MIT):** procedural memory keyed by normalized domain → ATS family
  (lesson learned on one Workday tenant transfers to all); six lesson
  categories; post-run extraction. ADOPT idea for staging robustness.
- **JobSpy (MIT, coasting):** clean per-site scraper interface; runs on
  borrowed private mobile-app API keys (Indeed/ZipRecruiter) + spoofed UAs —
  usable as an OPTIONAL swappable dependency, never load-bearing. LinkedIn
  module stays off.
- **ApplyPilot (AGPL — ideas only):** manual_ats/blocked/blocked_sso
  declarative blocklist shape; LLM-leak-phrase output check. Its apply stage
  bakes in paid CAPTCHA solving — disqualified.
- **AIHawk (30K stars):** application code deleted 2026; now markets a stealth
  browser. Historic code AGPL. Nothing to take.
- **GodsScion LinkedIn applier:** undetected-chromedriver + plaintext
  credentials + auto-submit spam. Nothing to take.

## LinkedIn position (ratified direction)

No logged-in LinkedIn automation (scraping, Easy Apply) — account-ban risk
lands on the user's own profile mid-search, and spec §2.5 already excluded it.
The LinkedIn VALUE ships anyway: saved-search email-alert ingestion + pasted
URL → resolve to employer ATS (the freehire-style URL recognizer makes any
pasted link land in the normal pipeline).
